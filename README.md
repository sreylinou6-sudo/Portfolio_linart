# Portfolio | LINART

A modern and responsive personal portfolio website for OU SREYLIN, built with HTML, CSS, and JavaScript. The site showcases projects, technical skills, contact information, and a bilingual English/Khmer experience with a light and dark mode toggle.

## Live Demo

- Portfolio Website: https://portfolio-linart.vercel.app/

## Features

- Responsive portfolio layout for desktop, tablet, and mobile
- English and Khmer language toggle
- Dark and light theme switcher
- Animated hero section with a typewriter effect
- Skills section rendered from structured JSON data
- Featured projects section with live demo and GitHub links
- Contact section with social media links and a form integration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- JSON data-driven content

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/sreylinou6-sudo/Portfolio_linart.git
cd Portfolio_linart
```

2. Open the project in a browser, or run a local server:

```bash
python -m http.server 8000
```

3. Visit:

```text
http://localhost:8000
```
